# Словарь терминов страницы «Инвестиционный климат Свердловской области»

Единое правило для страницы и будущих аналитических документов. Основной принцип: если существует точный русский эквивалент — используется русский. Английский термин сохраняется только для официальных названий иностранных организаций/систем, устоявшихся профессиональных обозначений (с пояснением при первом употреблении) и в техническом контексте.

- IDA Ireland — Ирландское агентство промышленного развития;

- PAIH — Польское агентство инвестиций и торговли;
- GTAI — Germany Trade & Invest, немецкое агентство внешней торговли и инвестиций;
- OECD — Организация экономического сотрудничества и развития (ОЭСР);
- Doing Business / B-READY — рейтинги Всемирного банка (архивный и новый);
- PDOK / Kadaster — национальная геоплатформа и кадастр Нидерландов;
- SIRM — механизм системного реагирования на проблемы инвесторов (Всемирный банк);
- Invest Lithuania, DBT Data Hub, DEWA, GNERC — сохранять как названия с кратким пояснением по месту.

## Тональность

Короткие предложения. Конкретные глаголы. Нейтральный деловой тон. Без рекламных оборотов, консультантского жаргона и цепочек из 5–7 существительных. Каждый вывод — с причиной и следствием.

Плохо: «Создание end-to-end CRM-контура с SLA-мониторингом investor journey».
Хорошо: «Создание единой системы сопровождения инвестиционного проекта с контролем сроков на всех этапах».
