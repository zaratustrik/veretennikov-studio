# Assets мастер-класса

Принцип: максимум процедурной графики (three.js/SVG), минимум внешних файлов.

## Процедурно (кода достаточно)
нейросеть-точки, машина правил, контекстное окно, кольцо 4П, цикл проверки, лестница, документ-хаб, маршрут агента, контуры безопасности, импульсы, wireframe.

## Внешние assets

## Asset ID: hero-campus-night
- Назначение: постер hero + fallback без WebGL
- Сцена: hero, finale
- Формат: AVIF + WebP fallback (из авторского рендера презентации, стр. 1)
- Размер: 1920×1080 ≤ 220KB; mobile 960×540 ≤ 80KB
- Desktop/mobile варианты: да
- Источник: собственный рендер автора (assets/originals/image-1-1.png)
- Права: автор (Веретенников А.)
- Статус: ⏳ конвертация
- Fallback: тёмный градиент CSS

## Asset ID: masterclass-og
- Назначение: Open Graph 1200×630 (рус.)
- Формат: PNG
- Статус: ⏳ (генерируется через opengraph-image.tsx)
