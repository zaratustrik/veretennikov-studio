# Проверка публичных страниц · 2026-09-08

## Охват

Единая система применяется к публичному коммерческому контуру: `/`, `/services`, `/services/*`, `/diagnostika`, `/production`, `/cases`, `/show/*`, `/programs`, `/blog`, `/about`, `/contact`, `/razbor`, `/brief`, thank-you и юридические страницы.

Отдельные продукты не включены в стилистическую унификацию: `/admin/*`, `/deck/*`, `/presentation/*`, `/p/*`, `/r/*`, `/b/*`, `/live/*`, `/ai-masterclass`, `/pamyatka/*`, `/karandash-brief`. Это рабочие приложения, презентации, закрытые клиентские пространства или служебные экраны со своими режимами использования.

## Что унифицировано

- одна шапка и один полный footer, включая страницы case-study;
- sans-serif типографика заголовков, cobalt для смыслового акцента;
- прямоугольные CTA и единое состояние focus;
- общий paper / ink / cobalt набор токенов;
- контент сразу виден: page transition и scroll reveal не задерживают чтение;
- skip-link, один `main`, клавиатурное mobile menu с `Escape` и `inert` для фонового контента;
- короткие схемы механизма на основных AI-услугах;
- быстрый якорь к форме на `/razbor`.

## Фактическая browser QA

Chromium, 1440×1000 и 390×844. Проверены 30 representative URL из публичного контура, включая все основные типы страницы. На проверенных URL: один `main`, один H1, горизонтального overflow нет. На mobile меню открывается кнопкой, фон становится inert, `Escape` закрывает меню и возвращает фон.

Representative case-study: `industrial-cooperation`, `road-analytics-platform`, `belojarskaya-aes`. Каталог содержит 64 опубликованных проекта; все используют общий `/show/[slug]` template, поэтому визуальная оболочка покрывает весь набор.

Форма `/razbor`: якорь ставит начало формы примерно под фиксированной шапкой; обязательные поля и consent сохранены. Заявка не отправлялась, запись в production БД и уведомления не тестировались.
