## Что сохраняем и аргументы против редизайна
Production уже ставит AI первым; разворот бренда заново не нужен. Сценарии описаны языком клиента, понятен бесплатный первый шаг, диагностика отделена от внедрения, есть право остановиться. Спокойная бумажная палитра, контрастная типографика и простые CTA подходят промышленному B2B. Есть отдельное production-направление, SEO-страницы услуг, реальные опубликованные кейсы. Их замена рискует потерять трафик и доверие без доказанного выигрыша.

## Три пути
Оценки относительные, без прогнозов процентов конверсии.

| Критерий | A · Conservative Evolution | B · Visual Rebalance | C · New Experience |
|---|---|---|---|
| Business impact | Умеренный: облегчить чтение | Высокий потенциал: быстрее задача + доказательство | Неопределённый: переучивание посетителя |
| Качественные лиды | Небольшой потенциал | Наиболее обоснованный: реальные проекты и конкретный вход | Потенциал высок, но внимание может уйти в интерактив |
| Риск | Низкий | Умеренный: качество visual evidence | Высокий: новые пути и структура |
| Сложность | Низкая | Средняя, ограничена главной | Высокая |
| Performance | Почти без изменений | Возможное улучшение: CSS/SVG вместо video-mark | Риск JS/медиа и задержки первого экрана |
| SEO | Минимальный риск | Низкий при сохранении маршрутов и metadata | Существенный при смене IA |
| Поддержка | Простая | Простая: SSR + один interactive island | Зависит от сложных компонентов |
| Соответствие бренду | Хорошее, но слабая демонстрация | Лучшее: инженерная ясность + visual craft | Риск выглядеть как digital-аттракцион |

Рекомендация B. Архитектура бренда: единая Veretennikov Studio; ведущее предложение — ИИ, автоматизация и цифровые системы; visual production — самостоятельная услуга и свидетельство опыта работы со сложной промышленной средой. Не 50/50, не искусственное «AI + видео = синтез» для каждого заказа.

Контраргумент: история production сама по себе не доказывает компетенцию AI. Поэтому два цифровых проекта должны быть видны раньше общего списка клиентов, а схемы нельзя называть реальными интерфейсами. Отсутствие разрешённых screenshots — реальный пробел доказательств, не повод генерировать фиктивные панели.

## Визуальный язык
Бумага / тёмные чернила / кобальт из существующих tokens. Чёткие тонкие линии, асимметричная сетка, небольшие моноширинные подписи. Большая типографика для обещания, схема для механизма, реальный кадр для масштаба среды. Никакого decorative AI imagery. Motion 160–220 ms только при действии: смена сценария, hover, focus. Нативные details для процесса и FAQ. Нет бесконечных циклов, таймеров, горизонтального mobile-scroll.

## Проверка бизнес-гипотезы
Показать старую и новую страницы сопоставимым B2B-респондентам отдельно. Через 10 секунд спросить «что компания делает / для кого», через 30 — «какой проект доказывает это / с чего начать». Не подсказывать AI. Зафиксировать долю правильных ответов и время до кейса/CTA. После согласованного запуска: CTA → начало формы → серверный success → квалификация лида в CRM. Главная метрика — квалифицированные обращения на релевантные сессии; клики по схемам лишь диагностика. Сегменты: mobile/desktop, поиск/прямой, AI/production. При малом трафике сначала качественные интервью, не псевдостатистический A/B.
