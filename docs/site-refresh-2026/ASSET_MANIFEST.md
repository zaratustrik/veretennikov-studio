## Следующие материалы, в порядке ценности
1. Разрешённый screenshot промышленной кооперации: запрос, структурирование, результат и оператор; скрыть данные по правилам владельца.
2. Разрешённый screenshot платформы дорожной аналитики с контекстом состояния/периода.
3. Короткий 6–10 s фрагмент реальной 3D/industrial работы, только по нажатию и с poster. Добавлять, только если он объясняет больше текущего кадра.
4. Подтверждённые результаты цифровых кейсов: baseline, измерение, период, масштаб, роль студии. Не заменять их красивой графикой.

Если последующий агент применит imagegen: добавить prompt, дату, модель/инструмент, путь, назначение, статус prototype/production и основание для использования. Нельзя генерировать «реальный интерфейс клиента».
