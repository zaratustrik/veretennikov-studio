# Investment Climate Web — Этап 2: информационная архитектура

Дата: 01.08.2026.

## 1. Разделы (порядок на странице = sticky-меню)

1. **Титул** (`#top`) — название, статус «аналитический проект / для обсуждения», дата данных (31.07.2026), счётчики объёма (43 мероприятия, 60+ документов, 25+ росс. практик, 30+ межд. практик, 37 предложений).
2. **Резюме** (`#summary`) — 7 выводов (тезис + 1–2 предложения + значимость + якорь) и «Решить в первую очередь» (7 решений, ранжированных: эффект/срочность/сложность/срок).
3. **Положение региона** (`#position`) — 11→10→14 место (динамика-линия), 5 показателей карты vs средние по РФ (сравнительная шкала), статус достоверности у каждой цифры, матрица «важность/состояние».
4. **Диагностика карты** (`#diagnostics`) — счётчики вердиктов (сохранить 12 / переработать 15 / объединить 4 / исключить 4 / проверить 1 / автоматизировать 1 / довести 1 / заполнить 4), доли формальных KPI, интерактивная матрица «влияние на рейтинг × влияние на инвестора» (клик → фильтр списка).
5. **43 мероприятия** (`#items`) — центральный модуль (см. §3).
6. **Карта проблем** (`#problems`) — 10 системных проблем → клик → отфильтрованные мероприятия.
7. **Путь инвестора** (`#journey`) — 12 этапов: сервисы/разрывы/строки карты/предложения (горизонтальный степпер, деталь по клику).
8. **Российские практики** (`#ru-practices`) — по 6 функциям.
9. **Международные практики** (`#intl-practices`) — по 9 функциям; маркировка применимости (4 уровня).
10. **Наши предложения** (`#proposals`) — 3 уровня (быстрые 3–6 мес. / системные 6–18 / цифровые).
11. **Новая карта** (`#new-roadmap`) — 30 строк по 5 блокам, сравнение «было/предлагается», горизонты 0–3/3–6/6–12/12–24.
12. **Методика** (`#method`) — 8 пунктов + ограничения.
13. **Источники** (`#sources`) — библиотека с фильтрами по 8 категориям.

## 2. Пользовательские сценарии

- **Министр (3 минуты):** титул → резюме → «решить в первую очередь» → (опц.) позиция региона. Всё выше первой трети страницы, без обязательного чтения.
- **Зам. министра (15 минут):** + диагностика + матрица → клики в 3–5 карточек → предложения.
- **Специалист (глубоко):** фильтры/поиск по 43 → карточка (8 вкладок) → источники → практики; deep link коллеге (`?item=31`).
- **Демонстрация на встрече:** presentation mode (клавиша/кнопка) → крупные слайды-блоки: резюме → позиция → диагностика → топ-мероприятия → предложения → новая карта; `?item=N` открывает карточку сразу.
- **Печать:** Ctrl+P → резюме, выводы, предложения, новая карта, источники; интерактив заменён статикой.

## 3. Центральный модуль «43 мероприятия»

- Desktop: таблица-гибрид (строка = компактная карточка-ряд): № · название (сокр.) · показатель · ответственный (сокр.) · исходный KPI (сокр.) · вердикт-бейдж · влияние на рейтинг (1–3) · влияние на инвестора (1–3) · приоритет · действие.
- Mobile: карточки.
- **Фильтры** (панель над списком, состояние в URL searchParams): показатель (5), вердикт (7 статусов), ответственный (3 группы: Министерство/АПИ/Минцифры+др.), влияние на рейтинг, влияние на инвестора, приоритет, тип проблемы (10 из карты проблем), наличие межд./росс. аналога, доказательность (A/B/C).
- **Поиск:** полнотекстовый по: исходный текст, KPI, заключение, предложение, ответственные, источники (клиентский, по подготовленному индексу в JSON).
- **Карточка** (drawer справа на desktop / fullscreen на mobile; URL `?item=N`; фильтры и скролл сохраняются):
  1. Исходная редакция (полный текст, показатель, критерий, срок, KPI, ответственные, ссылка на DOCX-источник);
  2. Заключение (вердикт, объяснение, сильные/слабые, риски формального выполнения, разрыв причинной цепочки, ограничения);
  3. Влияние (7 осей с текстовым объяснением);
  4. Рекомендация (бейдж + обоснование);
  5. Предлагаемая редакция (режим сравнения «Было | Предлагается»: активность, KPI, baseline, target, формула, источник данных, периодичность, владелец, stop-критерий, зависимости);
  6. Практики (карточки аналогов с применимостью);
  7. Источники (наименование, организация, дата, тип, ссылка, дата доступа, что подтверждает);
  8. Доказательность (шкала: официальный источник / несколько источников / аналитический вывод / гипотеза / данных недостаточно).
- Навигация в карточке: ← предыдущее / следующее →, «назад к списку», «копировать ссылку».

## 4. Связи сущностей

RoadmapItem ↔ Problem (n:m), RoadmapItem ↔ Practice (n:m via benchmarkIds), RoadmapItem ↔ Source (n:m), RoadmapItem ↔ NewRoadmapRow (mergedInto/replacedBy), Proposal ↔ RoadmapItem, JourneyStage ↔ RoadmapItem. Все связи — по id в JSON, рендер — ссылки-чипы.

## 5. Состояние и URL

- `?item=31` — открытая карточка; `?f=<encoded>` — фильтры; `?q=` — поиск; `?mode=present` — презентационный режим. History API: возврат не теряет состояние (диалог поверх списка, а не переход).
- Скролл-позиция списка сохраняется (карточка — оверлей).

## 6. Presentation mode

Класс `ic-present` на корне: скрыть фильтры/навигацию, крупная типографика (+25%), полноэкранные секции с snap-scroll, стрелки ←/→ по секциям, Esc — выход. Активация: кнопка в шапке.

## 7. Print mode

`@media print`: скрыть навигацию/фильтры/кнопки; развернуть резюме, позицию, диагностику (статистика), предложения, новую карту (таблица), источники (список). Карточки 43 — только сводная таблица (номер, вердикт, новый KPI). Разрывы страниц между секциями.
