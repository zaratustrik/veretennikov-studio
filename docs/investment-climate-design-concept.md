# Investment Climate Web — Этап 4: дизайн-концепция

Дата: 01.08.2026.

## 1. Характер

Государственно-деловой аналитический инструмент уровня заседания правительства: светлый, плотный по информации, без декоративности. Ощущение: доказательность, точность, управляемость. Референс тона — GOV.UK statistical releases + внутренние дашборды McKinsey, не стартап-лендинг.

## 2. Палитра (CSS-переменные, префикс `--ic-`, scoped в `.ic-root`)

| Токен | Значение | Роль |
|---|---|---|
| `--ic-bg` | `#F6F7F9` | основной фон |
| `--ic-surface` | `#FFFFFF` | поверхности/карточки |
| `--ic-surface-2` | `#F0F2F5` | вторичные поверхности, зебра таблиц |
| `--ic-line` | `#DDE1E7` | границы |
| `--ic-ink` | `#1A1E26` | основной текст (графит) |
| `--ic-ink-2` | `#4B5563` | вторичный текст |
| `--ic-accent` | `#1E4FA3` | единственный холодный акцент (глубокий синий): ссылки, активные фильтры, фокус |
| `--ic-accent-ink` | `#173E82` | hover акцента |

Статусные (только функционально, всегда с текстовой меткой):

| Токен | Цвет | Статус |
|---|---|---|
| `--ic-s-keep` | `#1E7F4F` (зелёный) | сохранить / масштабировать |
| `--ic-s-improve` | `#B7860B` (жёлтый тёмный) | доработать |
| `--ic-s-rewrite` | `#C25E0A` (оранжевый) | существенно переработать |
| `--ic-s-remove` | `#B3261E` (красный) | исключить / критический риск |
| `--ic-s-new` | `#1E5FA3` (синий) | новое предложение |
| `--ic-s-nodata` | `#6B7280` (серый) | данных недостаточно / формальная активность |

Фоны бейджей — те же цвета на 10–12% opacity, текст — полным цветом (контраст ≥4.5:1 проверен).

## 3. Типографика

- Заголовки/акценты: **IBM Plex Sans** (cyrillic; строгий гротеск, есть табличные цифры) через `next/font`, переменная `--font-ic`.
- Текст: Inter из корневого layout (наследуем).
- Цифры KPI: `font-variant-numeric: tabular-nums`.
- Шкала: h1 34/40, h2 26/32, h3 19/26, body 15.5/24, small 13.5/20, caption 12/16; длинные тексты — `max-width: 72ch`.
- Названия органов НЕ сокращать в карточке; в списках — аббревиатуры с `title`-атрибутом.

## 4. Сетка и компоненты

- Контейнер 1280px max (списки — до 1440), отступы 24/32; секции — 96px вертикального ритма.
- Компоненты: `StatusBadge` (цвет+текст), `ImpactDots` (1–3 + подпись), `MetricCard` (число+дата+источник+статус достоверности), `FilterBar` (чипы, счётчик, сброс), `ItemRow`/`ItemCard`, `ItemDrawer` (вкладки), `CompareView` («Было|Предлагается» двухколоночно, на mobile — переключатель), `EvidenceTag` (шкала доказательности), `SourceCard`, `PracticeCard` (+бейдж «заявлено/подтверждено»), `Matrix` (SVG 3×3, кликабельные сегменты), `TrendLine` (SVG: 11→10→14), `JourneyStepper`, `AnchorNav` (sticky, активная секция), `PresentButton`, `PrintHint`.
- Диаграммы: рукописный SVG (без chart-библиотек): линия динамики, сравнительные шкалы (5 показателей vs средняя РФ), матрица. У каждой — подпись, источник, дата.

## 5. Анимация (framer-motion уже в проекте)

- Появление секций: fade+8px rise, 300ms, stagger 60ms, один раз (viewport once).
- Числа титула: count-up 600ms.
- Drawer: slide-in 240ms.
- Фильтры: layout-анимация списка 200ms.
- `prefers-reduced-motion`: все анимации отключаются (motion `useReducedMotion`).
- Запрещено: параллакс, фоновые движения, 3D.

## 6. Ключевые экраны (словесные макеты)

1. **Титул:** левая колонка — название (h1), статус-плашка «Аналитический проект · для обсуждения», период, дата данных; правая — 5 счётчиков в MetricCard-сетке 2×3.
2. **Резюме:** 7 карточек-выводов (номер, тезис жирно, объяснение, значимость-бейдж, стрелка-якорь) в сетке 2 колонки; справа sticky-колонка «Решить в первую очередь» — нумерованный список с мини-метками эффект/срок.
3. **Список 43:** FilterBar сверху (чипы группами, поиск справа), таблица-гибрид; строка — grid 12 колонок; вердикт-бейдж и две группы ImpactDots видны без скролла.
4. **Карточка:** drawer 720px, заголовок (№, название, бейджи), горизонтальные вкладки (8), футер — prev/next/copy-link.
5. **Presentation mode:** секция = экран, 60% масштаб контента → 125% типографика, тёмная нижняя полоса прогресса разделов.

## 7. Доступность

Фокус-кольца `--ic-accent` 2px; все интерактивы — кнопки/ссылки с aria; drawer — role=dialog, focus trap, Esc; фильтры — aria-pressed; цвет никогда не единственный носитель смысла; контраст текста ≥4.5:1, крупного ≥3:1.
